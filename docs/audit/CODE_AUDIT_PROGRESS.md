## Цели

- Проверить весь исходный код, конфигурацию сборки, тесты и CI.
- Удалить лишний код и упростить критические пути.
- Оптимизировать быстродействие без изменения характеристики `Fl(3).W.16.5s`.
- Снизить энергопотребление там, где это не ухудшает отзывчивость Zigbee.
- Снизить количество лишних пробуждений CPU, блокировок, записей NVS и ADC-операций.
- Проверить конкурентный доступ, таймеры, переполнения, гонки и повторные вызовы.
- Сохранить совместимость со стандартными Zigbee HA/ZCL-кластерами.
- Не менять эталонную аппаратную схему без отдельного решения владельца проекта.
- Каждое изменение сопровождать тестом или явной записью причины, если тест неприменим.

### Ограничения, которые нельзя нарушать

- Период: `16.500000 s`.
- Последовательность: три вспышки `Fl(3).W.16.5s`.
- Текущая LUT-огибающая не меняется без отдельного обоснования.
- Рабочая частота внешнего LED PWM: 1 кГц, проверена на реальном модуле.
- Zigbee остаётся стандартным HA/ZCL без подмены сторонних model ID.
- Текущий режим радио — always-on End Device; переход в sleepy mode возможен только как отдельное решение после оценки задержки управления.
