# Политика безопасности

## Поддерживаемые версии

В настоящее время поддерживается только актуальное состояние ветки `main`.

## Сообщение об уязвимости

Не публикуйте в открытом issue:

- токены и ключи;
- дампы с персональными данными;
- приватные Zigbee-ключи;
- сведения, позволяющие скомпрометировать реальную сеть.

Если в репозитории доступна функция **Security → Report a vulnerability**, используйте её для приватного сообщения.

Если приватная форма недоступна, создайте минимальный issue без технических деталей с просьбой связаться приватно с владельцем репозитория.

## Аппаратная безопасность

Проект работает с Li-ion аккумулятором, преобразователями питания и внешним 12-вольтовым LED-модулем. Любые изменения силовой части должны проверяться с отключённым питанием и, по возможности, через источник с ограничением тока.
